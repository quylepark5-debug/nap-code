# Hướng dẫn sử dụng & sơ đồ chân

Mỗi dự án có 1 thư mục (tên = mã dự án), gồm 4 file:

| File | Nội dung |
|---|---|
| `thuong.md` | Hướng dẫn **Bản thường** |
| `pro.md` | Hướng dẫn **Bản Pro** |
| `thuong-chan.txt` | Sơ đồ chân **Bản thường** |
| `pro-chan.txt` | Sơ đồ chân **Bản Pro** |

## Cách viết hướng dẫn
- `## Tiêu đề` → tiêu đề mục
- `1. Bước` → danh sách đánh số
- `- Ý` → gạch đầu dòng
- `**chữ**` → chữ đậm
- Dòng trống → tách đoạn

## Cách viết sơ đồ chân
Mỗi dòng: `Linh kiện | Chân linh kiện | Chân ESP32 | Ghi chú (không bắt buộc)`

Ví dụ: `Nút B1 | Chân 1 | GPIO4 | nhấn nối GND`

Sửa xong bấm **Commit changes**, trang nạp tự cập nhật sau khoảng 1 phút.
